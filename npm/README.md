# Repo Atlas

Read a GitHub repository once and explore it as five layers, a mind map, and answers written from the code.
Runs on your machine; bring your own model (Ollama or a Claude API key).

```bash
npm create repo-atlas
```

The app is a Python package that ships inside this one; the launcher runs it through [uv](https://docs.astral.sh/uv/) (and offers to install
uv if it's missing). Needs git. Full docs in the project README.
